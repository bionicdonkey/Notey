# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/bionicdonkey/Notey/security/advisories/new)
rather than opening a public issue. Include what you found, how to reproduce it, and the version
you tested. I will acknowledge the report as soon as I can and credit you in the fix if you wish.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
